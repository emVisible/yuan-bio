# 冷启动指南 — 收集 10–20 个真实用户反馈

上线后第 3–4 周执行。目标：验证产品可用性、模板偏好、付费意愿，而非追求流量。

## 准备清单

- [ ] 部署到 Vercel，绑定域名（如 matchbiodata.com）
- [ ] 配置 Lemon Squeezy 支付（或先用 Demo unlock 收集反馈）
- [ ] 准备 1 张产品截图（填好示例数据的预览页）
- [ ] 自己先完整走一遍流程，导出 PDF

## 发帖渠道与话术

### 1. 一亩三分地 Life 版

**标题示例：**
> [工具分享] 做了个海外华人相亲简历 PDF 生成器，求试用反馈

**正文要点：**
- 说明动机：「帮朋友整理相亲资料，干脆做了个工具」
- 强调：无需注册、数据不上传、中英双语
- 明确求助：「求 10 位朋友试用，告诉我哪里难用」
- 附链接，不要硬广语气

### 2. 小红书

**笔记结构：**
- 封面：预览 PDF 截图
- 标题：海外华人相亲简历怎么做｜5分钟PDF模板
- 正文：痛点 + 3 步教程 + 工具链接放评论区或主页
- 标签：#海外相亲 #北美脱单 #相亲简历 #华人婚恋

### 3. 北美华人 Facebook 群

搜索 "华人相亲" "北美单身" 等群组，发短帖：

> 最近做了个免费的相亲简历制作网站，填表就能出 PDF，适合发微信群。还在完善中，欢迎试用给建议：[链接]

### 4. Reddit（软性）

- r/ChineseAmericans
- r/AsianMasculinity / r/AsianAmerican（视规则而定）

标题用求助口吻：
> I built a marriage biodata PDF tool for overseas Chinese — would love feedback

## 反馈收集表（可复制到 Google Form）

1. 您在哪里使用相亲简历？（北美/加拿大/澳洲/其他）
2. 填表流程是否顺畅？（1–5 分）
3. 您最喜欢哪个模板？（简约/传统/现代）
4. 缺少哪些字段？
5. 您是否愿意为无水印 PDF 付费 $4.99–9.99？
6. 开放建议

## 目标指标（4 周内）

| 指标 | 目标 |
|------|------|
| 试用用户 | 10–20 人 |
| 完成填表 | ≥ 50% |
| 导出 PDF（含水印） | ≥ 30% |
| 付费转化 | ≥ 1 笔（验证意愿） |
| 有效文字反馈 | ≥ 5 条 |

## 反馈后迭代优先级

1. 用户普遍抱怨的字段缺失 → 立刻加
2. 模板偏好 → 优化默认推荐
3. 移动端问题 → 优先修
4. SEO 和内容 → 第 2 月起加大投入

## 注意事项

- 不要在多个渠道同一天刷屏发帖
- 回复每一条反馈，建立信任
- 有人付费后第一时间感谢并问体验
- 隐私：提醒用户分享链接时只发给信任的人
